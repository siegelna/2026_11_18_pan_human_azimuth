# pan_human_azimuth

Label inventory for the Pan-human Azimuth cell type models.

- Paper: [bioRxiv preprint](https://www.biorxiv.org/content/10.64898/2026.07.16.738997v1.full.pdf)
- Vignette: [satijalab.org/pan_human_azimuth](https://satijalab.org/pan_human_azimuth/)

## Setup

```bash
conda env create -f environment.yml
conda activate pan-human-azimuth
```

## Usage

Run the scripts in `Python/` in order (`00` through `10`). Outputs go to `tables/`.
